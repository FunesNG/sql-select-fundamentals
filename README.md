# sql-select-fundamentals

¿Por que es una mala práctica usar SELECT * en producción?
Se considera mala practica ya que entorpece el rendimiento del sistema al generar un consumo innecesario de recursos y traer columnas que no son necesarias.

¿Por qué son importantes los alias para un stakeholder no técnico?
Porque transformar nombres técnicos, abreviaciones o código en alias completamente legibles para cualquier tipo de persona.
